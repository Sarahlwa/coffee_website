# ☕ Coffee Shop Website

A modern coffee shop website built using HTML, CSS, and JavaScript. This project focuses on creating an attractive, user-friendly interface to showcase coffee products and provide visitors with an enjoyable browsing experience.

## ✨ Features

- ☕ Attractive coffee shop design
- 🛍️ Coffee product showcase
- 📱 Responsive layout for different screen sizes
- 🎨 Custom styling and visual effects
- 🧭 Easy-to-use navigation
- ⚡ Interactive elements using JavaScript

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layouts, and responsive design
- **JavaScript** – Interactive functionality

## 🚀 Getting Started

Follow these steps to run the project locally.

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser, or use the Live Server extension.
